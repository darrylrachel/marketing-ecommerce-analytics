# Marketing & E-Commerce Analytics Project

A complete end-to-end analytics system built using SQL, Python, and Tableau on a realistic multi-table marketing dataset.

This project analyzes customer behavior, marketing funnels, campaign uplift, revenue patterns, product performance, and A/B testing results.


## 📂 Project Structure
/sql        → all SQL queries (funnels, segmentation, revenue, AB tests)
/python     → EDA, cleaning, feature engineering
/tableau    → dashboard files (.twbx)
/erd        → schema diagrams


## 🎯 Project Objectives
- Understand full e-commerce funnels
- Analyze marketing campaign performance
- Measure uplift and A/B test results
- Perform customer segmentation
- Explore product pricing & revenue analytics
- Clean & model event-level behavioral data
- Build executive dashboards in Tableau

### 📊 Dataset Description
- This project uses a realistic synthetic dataset containing:
- 5 relational tables (campaigns, customers, events, products, transactions)
- 41 columns
- Millions of behavioral events
- Campaign exposure + experiment groups for uplift modeling
- Realistic marketing noise: missing values, inconsistent casing, seasonal patterns
